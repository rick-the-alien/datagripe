Getting the vibrance back

The frozen single layer in your screenshot looked right and the composited one looked like a sorbet, which localises the fault precisely: the ramp was fine, the compositing was destroying it.

The cause was mix-blend-mode: screen on the second colour layer. Screen is additive — it can only ever move a pixel toward white. Screening magenta over green produces something close to white, so every point where the two layers disagreed on hue got bleached. The more the layers drifted out of phase, the more of the bar was bleached, which is why the moving version looked pastel and the frozen one did not.

The fix

Stop blending colour with colour. There is now exactly one colour layer, always at full saturation, and the other two layers are neutral dark waves that only modulate brightness. Hue is never averaged with another hue, so no pixel can drift toward grey. The non-repeating quality survives because the two dark waves still run at 11 and 23 seconds against the colour layer's 17.

Push it further

Two extra dials. Saturation is a filter on the container, so it lifts the whole stack without touching the palette definition. Dim depth controls how dark the neutral waves get — heavy dimming reads as dramatic but costs apparent vibrance, since a dimmed saturated colour still looks duller.

On the cyan

One honest caveat. #5EEAD4 is a genuinely pale colour — high lightness, moderate chroma — so it will always read softer than the other three no matter how the layers composite. If the bar still feels light after this, that band is why, and the fix is a deeper cyan in motion contexts rather than more filtering. Something around #14D9C4 holds the same hue with more depth, and you would keep #5EEAD4 for static interface use where it sits on small text and needs the lightness.

The CSS

.bar{ position:relative; height:4px; overflow:hidden; background:#0B0E14;
  filter:saturate(1.22) }

.colour{ position:absolute; inset:0; width:200%;
  background:var(--ramp); animation:drift 17s linear infinite }

.wave{ position:absolute; inset:0; width:200%; mix-blend-mode:multiply;
  background:linear-gradient(90deg,rgba(11,14,20,.5),transparent 25%,
    rgba(11,14,20,.4) 50%,transparent 75%,rgba(11,14,20,.5));
  animation:back 11s linear infinite }

.wave2{ /* same idea, different shape and phase */
  animation:drift 23s linear infinite }
The rule to carry forward: neutral layers may multiply, colour layers may not blend with each other. Any future layer that introduces a second hue will re-open the same washout, whatever blend mode it uses.
